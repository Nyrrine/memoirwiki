# Rights and third-party material

## No licence is granted

There is deliberately no `LICENSE` file. All rights are reserved.

This is a fan project built on assets that are not the author's to license.
Publishing it under a permissive licence would have told the world it may
freely reuse and sell Project Moon's artwork, which is not something this
project can grant, and would sit badly with the fan-content allowance the site
relies on. Reserving everything grants nothing and claims nothing.

The source is public to read, to learn from, and to audit. It is not offered
for reuse. If you want to do something with it, ask.

## Limbus Company assets

Everything under `public/bg/`, `public/icons/` and `public/ui/` - character
art, skill icons, status icons, backgrounds and UI furniture - is the property
of **Project Moon**, taken from Limbus Company.

This project is not affiliated with, endorsed by, or connected to Project Moon,
and claims no ownership of or licence to these assets. They are included so the
toolkit can render identity cards that look like the game's. If Project Moon
would prefer they were not distributed here, they will be removed.

`public/ui/whats-new-art.webp` is Don Quixote birthday art, sourced through the
community-run Limbus Company wiki rather than from the game files, and recoloured
only to the extent of lifting its flat grey background to transparency. Same
standing as everything else here: Project Moon's, included so the site can look
like the game, removed on request.

The site accepts donations only to cover its running costs. It does not sell
anything, and nothing derived from Project Moon's assets is sold.

text, not merely a reference to it, so **`public/fonts/OFL.txt`** reproduces

### Fonts removed rather than shipped

Five were previously bundled and are no longer distributed, because their terms
did not clearly permit it or because nothing used them:

- **`KOTRA_BOLD.ttf`** - "Copyright 2020 KOTRA. All right reserved."
  (sic), with no licence field at all - only a URL - and so no redistribution
  grant. Replaced by Pretendard Bold, which is the same family
  as the body font and genuinely OFL. The one wiki page using it was migrated.
- **`SCDream5.otf`** - an explicit EULA permitting use only "as permitted by
  the EULA for the product in which this font is included". Unused.
- `Corporate-Logo-Bold-ver2.otf` (OFL 1.1), `HigashiOme-Gothic-C-1.3.ttf`
  (free software), `PerfectDOSVGA437.ttf` (no licence string) - all unused.
